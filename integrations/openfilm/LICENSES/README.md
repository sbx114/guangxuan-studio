# OpenFilm Studio UI 依赖许可

这些完整许可文本来自本次集成依赖的原始 npm 包文件，未改写作者署名和许可条款。它们补充 `THIRD_PARTY_NOTICES.md` 中的组件来源摘要，适用于构建后的 Studio UI 随源码和桌面包再分发。

包括 Inter、React / React DOM、Lucide、React Flow、zustand、classcat，以及 d3 的相应模块。`manifest.json` 记录包版本和每份原始许可的 SHA256。文件名中的依赖后缀表示 pnpm 的解析上下文。

建议随 `integrations/openfilm/LICENSES/` 分发，并从该集成的第三方说明中引用此目录。Inter 字体的 SIL OFL 1.1 许可全文位于 `@fontsource-variable+inter@5.3.0--LICENSE`。
