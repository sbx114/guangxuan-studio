# 光宣工作台

面向学院宣传的 Windows 桌面创作应用。当前完成 **视频剪辑** 和 **文案写作** 两个工作区；首页第三个入口“科普工作室”为后续规划。

同一份资料可以先转成宣传文案与分镜，再交给视频工作区编排素材、制作 Remotion 动画和导出 MP4。模型生成可编辑的方案，使用者确认事实与最终内容。

## 当前功能

| 工作区 | 可以完成的工作 |
| --- | --- |
| 视频剪辑 | 导入和预览视频、音频、图片；修剪、分割、调整顺序；添加字幕与配乐；按16:9、9:16或1:1导出720/1080规格的MP4 |
| AI粗剪 | 依据素材元数据、脚本和要求生成剪辑建议，检查后应用到可编辑时间线 |
| AI动画 | 文本模型编排结构化方案，用户可编辑JSON，再由本机Remotion渲染并加入素材库 |
| 文案写作 | 导入资料、提取并确认事实，生成推文、海报文案、视频分镜和社群文案，支持编辑、改写与核查 |
| 导出与协同 | 导出Word、Markdown、海报PNG、项目JSON及制作记录；分镜和旁白可送入剪辑 |
| 科普工作室 | 规划中，尚未实现独立工作流 |

AI粗剪依据素材名称、类型、时长、尺寸及脚本文字，不进行视频画面识别。字幕来自手动输入或脚本文案估时，首版不包含语音识别。Remotion支持标题、步骤、数据条、引用、收尾五类模板，模型不会生成并执行任意代码。

## Windows桌面启动

完整解压 **光宣工作台-Windows-x64** 目录，双击 **启动光宣工作台.cmd**。该兼容入口使用已安装的Node.js 24和Microsoft Edge，以独立应用窗口打开工作台。它支持真实媒体导入、文案、Remotion动画及MP4导出；本机已有所需Node与Edge，无需重新安装。

本机组织DeviceGuard策略阻止了新Electron可执行文件启动，因此提供标准Edge独立窗口入口，不修改组织策略。目录中的 **光宣工作台.exe** 保留给允许运行的设备。请保留完整资源目录；关闭窗口后可双击 **停止本地服务.cmd** 结束后台本地服务。

兼容窗口使用Edge；Electron版动画渲染可使用本机Edge或Chrome。发行目录包含FFmpeg与FFprobe。兼容启动的本地数据存放在 `%LOCALAPPDATA%\GuangxuanStudio`。

### 安装到桌面

兼容版可安装到 `%LOCALAPPDATA%\Programs\GuangxuanStudio`，并创建桌面的“光宣工作台”快捷方式。应用程序与项目数据分开存放；安装时不复制密钥、浏览器配置或用户媒体。

完整解压程序包后，可运行 `scripts/install-desktop.ps1 -SourceRoot '完整程序包目录'`。安装器只使用现有Node与Edge，不修改系统策略；安装结束后回读验证快捷方式，并执行不打开窗口的依赖检查。

### 从源码运行

需要 **Node.js 24或更高版本**。在项目根目录运行：

```powershell
npm install
npm start
```

`npm start` 是Electron入口。受本机策略限制时，安装依赖后可双击源码目录中的 **启动光宣工作台.cmd**，或使用下面的本地浏览器入口。

本地浏览器预览可运行：

```powershell
node server.mjs
```

也可使用 `npm run web`，打开终端显示的本机地址。浏览器与兼容窗口通过文件选择和本机流式上传导入媒体，每个文件最多2GB；不需要把视频转为Base64。Electron版另外提供原生文件路径选择和系统加密密钥保存。

源码模式需提供FFmpeg与FFprobe。可设置 `GUANGXUAN_BIN_DIR` 指向同时包含二者的目录，或分别设置 `GUANGXUAN_FFMPEG`、`GUANGXUAN_FFPROBE`；也支持项目 `bin/` 目录与系统PATH。

Windows打包命令为 `npm run build:win`。底层使用Electron、React、Remotion与FFmpeg，依赖版本以 `package.json` 和锁文件为准。

## 接入大模型中转站

打开 **模型连接**，填写接口基础地址、模型名称和API密钥。例如地址可为 `https://your-provider.example/v1`，不要填写网页控制台地址。

- 支持Chat Completions与Responses，按服务商能力选择。
- 模型列表不可用时，手动填写服务商提供的模型ID。
- JSON模式仅在接口与模型支持时开启。
- “测试连接”发送一次真实的短请求，可能计入服务用量。

文案、粗剪与动画编排共用文本模型。Remotion动画在本机渲染，无需另配文生图密钥。真实供应商接口仍需使用你自己的配置验证；预置示例不代表已完成供应商实连。

密钥默认仅保留在当前会话。Electron版可选择 **在本机加密保存密钥**；Edge兼容窗口保持会话密钥。项目保存在本机；主动使用AI功能时，相应素材、事实或脚本会发送到配置的接口。应用不会自动向公众号或社交平台发稿。

### 连接失败的排查

“模型连接”页先检查本地工作服务，并显示当前窗口地址。测试连接与获取模型列表会先确认本地服务可用，再发送模型请求。

- 如果显示本地服务没有响应，请重新双击桌面启动入口，在新窗口中操作。旧窗口可能仍连接已经关闭的端口。
- 如果显示身份验证、模型不存在、额度或中转接口网络错误，再检查中转站配置。它们与本地工作服务断开是不同问题。
- 启动入口会复用仍然健康的服务，并保持已选定的端口。需要加载后端更新时，先保存项目，再使用“停止本地服务.cmd”停止，随后重新启动。

应用不会自动把密钥重新发送到其他本地端口。

## 验证与文档

自动检查命令：

```powershell
npm test
```

运行真实媒体与动画集成测试：

```powershell
$env:GUANGXUAN_BIN_DIR = 'C:\path\to\ffmpeg-bin'
$env:GUANGXUAN_TEST_ANIMATION = '1'
node --test tests/video.test.mjs
```

真实媒体测试已验证剪切拼接、静态图片段、中文字幕烧录、混音、Range预览和重启恢复；动画测试验证Remotion生成MP4、注册素材、进入时间线并再次导出；上传测试验证原始文件流式导入、媒体信息探测和Range预览。测试使用合成素材和明确标注的动画方案，不是实时AI创作或宣传成效测试。

## 设计与开源

初始界面采用暖灰配色、玻璃档案阵列、悬停抽取和短暂展开动效，设计方向参考用户指定的 [RhineLabUI](https://github.com/LBEILC/RhineLabUI)。纸色Remotion模板也沿用细线、透明档案层和文字遮挡揭示。界面尊重“减少运动”偏好。本项目未复制其游戏或3D素材。

应用源码采用 [MIT许可证](LICENSE)。Remotion、FFmpeg等依赖及外部照片、标识、网页材料遵循各自许可证和使用条件。发布仓库时只分享源码与公开示例，真实项目、连接配置、密钥和私人媒体保留在本机。
