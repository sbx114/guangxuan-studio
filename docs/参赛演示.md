# 光宣工作台参赛演示

## 作品定位

建议名称：**光宣工作台——面向学院宣传的AI写作、动画与剪辑应用**。

一份活动或科研资料可以先形成多种宣传文案，再让分镜接入视频制作。当前完成视频剪辑与文案写作；科普工作室为规划入口，不作为已完成功能汇报。

项目特点落在具体流程：来源核对、事实确认、多种文案生成、文案转入剪辑、可编辑动画方案、本地真实渲染与成片导出。已有模型负责文字处理与编排，应用将能力整合到可操作的工作区。

## 三分钟协同演示

使用日期已经核对的公开学院材料，提前准备素材、方案和真实操作录屏。以下180秒是排练分配，不是通知规定的单队展示时长；模型请求与渲染等待按实际情况安排。

本机演示使用 **启动光宣工作台.cmd** 打开的Edge独立窗口。兼容入口依靠现有Node与Edge运行真实创作功能；本机DeviceGuard阻止新Electron程序，不影响采用该标准入口演示。媒体可从文件选择器真实导入，不依赖Electron原生接口。

| 时间 | 操作 | 讲解重点 |
| --- | --- | --- |
| 0:00—0:20 | 首页进入文案项目 | 工作台连接写作和视频制作，科普入口留待后续版本 |
| 0:20—0:50 | 展示来源、确认事实与分镜，点击文案转入剪辑 | 同一份资料生成多种表达，分镜继续用于视频 |
| 0:50—1:25 | 展示AI动画JSON，修改标题或步骤，渲染并查看结果 | AI编排可编辑方案，本机五类模板真实渲染为MP4 |
| 1:25—2:05 | 动画加入时间线，与本地素材编排；展示粗剪建议及人工修剪或分割 | 粗剪依据元数据和脚本，建议由人检查；动画也能继续剪辑 |
| 2:05—2:35 | 调字幕时间、配乐音量与画幅，提交或打开完成的导出 | 实际拼接画面、混音、烧录字幕并输出MP4 |
| 2:35—3:00 | 播放成片，展示项目记录与文案导出 | 展示资料—文案—动画—剪辑的协同，以及来源、提示词和人工修改 |

等待较长时，切换事先录制的同流程真实操作视频，并说明录制状态。已有成片也应标明，不把录屏或预先结果说成现场刚生成。

## 没有密钥时如何演示

可打开预置写作示例，把分镜送入剪辑，再用预置动画方案进行真实渲染和剪辑。明确说明：**“文本或方案是预置演示，非本次实时AI生成；动画渲染和成片导出由本机实际执行。”**

供应商实连需用参赛者自己的接口、模型和密钥验证。正式展示AI生成前，完成真实调用并保留提示词和记录；不能把预置示例计为模型调用或试用成绩。

## 需要准确说明的边界

- **AI粗剪**：依据素材元数据、脚本及要求，当前没有视频画面理解。
- **字幕**：来自手动输入或文案估时，当前没有语音识别。
- **AI动画**：生成受约束的JSON方案，由Remotion固定模板渲染；不是通用文生视频模型。
- **文案核查**：辅助提示，不能替代人工判断。
- **科普工作室**：仍为规划；科研科普写作示例不代表独立模块已完成。

图表数字应来自可靠材料；没有采访记录时，不生成署名的“原话”。公开网页是示例素材来源，不代表对本软件的认可或背书。

## 已有验证与待测成效

本地程序测试覆盖文案后端与媒体处理。真实媒体集成测试验证剪切拼接、图片片段、中文字幕烧录、混音、Range预览和重启恢复；动画集成测试完成“Remotion生成MP4—注册素材—时间线裁剪—再次导出”；新增上传测试验证兼容模式的文件流式导入、媒体探测与Range预览。

这些是功能验证，**不是工时节省、内容准确率或用户满意度的实证**。供应商实连与宣传应用效果需另外测量。

建议比较活动宣传、科研科普写作、讲座回顾三类公开任务。固定素材和交付要求，记录原流程与应用辅助流程，并说明熟练度、任务顺序及样本数。

| 待测指标 | 记录方式 |
| --- | --- |
| 总工时 | 包括整理、等待、核查、返工、剪辑和导出，不仅统计模型等待 |
| 事实问题 | 检查人物、日期、数字、限定词的错误、遗漏与无依据新增 |
| 人工修改 | 保存修改前后内容与原因 |
| 成稿与成片一致性 | 对照分镜、字幕和成片中的关键事实 |
| 可用性反馈 | 保留真实试用者、任务与原始意见，不预写好评 |

未测量时写为“验证计划”；少量样本按案例说明，不扩大为普遍结论。
