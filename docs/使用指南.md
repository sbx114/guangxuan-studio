# Gx 使用指南

## 让AI助手下载论文与教材

在首页或工作区打开 **AI助手**，使用 **自动处理**，输入“下载这篇论文的PDF”并附公开链接；也可以让助手先搜索、阅读论文页面，再找到原文件直链下载。无需先创建项目。只有原文件真正保存后才会出现文件卡，卡片显示名称、大小和 **保存原文件** 入口。关闭窗口、停止后续步骤、刷新页面或重启服务，都不会清除已完成的下载；可继续询问“列出已下载资料”。

需要制作科普视觉小说时，打开目标科普项目，说“下载并把这篇资料导入当前项目”，助手可在同一要求内依次下载和导入；已有下载时也可说“把刚下载的资料导入当前项目”。PDF、DOCX、TXT和Markdown会按原始字节导入资料库，解析页段后继续原有的三步制作流程。助手不会擅自选择人物、背景或替换已有页段范围。仅问答模式可以解释和找资料，需要实际下载或导入时切换到自动处理。

下载单个原文件最多64 MiB，可同时下载2份；科普解析仍遵循PDF32 MB、DOCX10 MB、文本8 MB的导入容量。下载区保存在本机应用数据目录下，保存的原文件不会被截成网页摘要；登录验证或受限站点需要提供可公开访问的文件链接。

## 一句话让助手处理图片和视频

打开目标项目和 **AI助手**，选择 **自动处理**，直接说明来源和目标。助手会自己安排搜索、下载、校验、导入及后续处理，不需要手动逐个调用工具。例如：“从这个官网找公开视频，导入当前工程，剪出20秒并加标题”，或“把这个视频识别整理成科普资料并导入当前项目”。模型沿用已有连接；处理到不支持的接口或无可用素材时会说明实际阻碍。

在**视频项目**中，图片和视频原文件会真正进入当前原生素材库；助手随后读取实际素材ID、时长和允许范围再剪辑，空素材工程也支持。进度会区分“已下载”“已导入素材库”和“已修改时间线”，仅下载或入库不会被说成成片完成。视频网址沿用200MB、180秒和同时2项的限制，支持视频直链及受支持的B站/YouTube公开单视频。新导入素材可继续用于本轮目标；默认整个当前工程可操作，本轮对话明确限定的素材/时间范围才是约束。

在**科普项目**中，图片先通过视觉模型识别可见文字和图表；视频在前300秒内最多抽取3帧，有音轨时尝试兼容ASR，再把实际成功的图片识别、画面整理和音频转写组合为TXT资料。导入结果列明来源、抽样时间和待核对之处。接着在制作页选择本次页段、公用人物和场景，再生成互动讲解；媒体文件不会自动成为人物立绘或背景。

当前模型不接受图片或没有识别到可用内容时，助手会说明未完成识别/导入，原文件仍保留。ASR失败时可只保留成功识别的画面资料并明确“未转写”；部分音频只记录实际成功返回的片段，不能当作整部视频逐字稿或精确字幕时间。视频抽样不代表完整观看，图片OCR也不等于自动解析整本扫描PDF。需要更换模型时，在现有“模型连接”配置兼容视觉或语音接口后再继续。

## 打开与选择项目

双击桌面的 **Gx** 快捷方式，或完整程序目录中的 **Gx.exe**。兼容入口 **启动Gx.cmd** 使用已有Node.js 24和Edge独立窗口。兼容窗口关闭后会保留后台；需要关闭服务或加载更新时，先保存工作，再使用程序目录中的停止或重启入口。

Gx默认播放原来的文字开场，保留逐字、描边、环线和欢迎转场，结束后直接进入波浪档案总览，阵列先连贯起伏一次，再恢复待机，开场不再自动拉近文档；三维场景默认使用原有完整效果。设置里只有 **原画／流畅** 两档：原画保留完整材质和光影，流畅降低渲染开销。选择会自动保存，“重播启动”可再次观看文字开场。

首页的每条功能波浪对应一类项目：视频、文案、科普各占一条，同类档案沿该波浪连续排列。按 **← / → 横向移动到另一条功能波浪，↑ / ↓ 沿当前波浪切换项目，Enter 查看信息，Esc 返回**。切换时保留其它波浪的档案，回来后继续选中该类上次的项目；空类别也会移动到自己的波浪位置。也可以点底部箭头。进入功能后，顶部只显示Gx、当前功能与返回档案等必要入口；切换功能时先返回档案。背景空槽不能误打开。输入框和编辑器内部仍保留各自的方向键功能。

项目信息里可修改名称、简介和封面。选择预置样式，或点“上传图片”使用自己的JPG、PNG、WebP（原图最多20MB，自动在本机缩小）。自定义图片按原比例居中裁切并铺满整个正面，原标签会隐藏；预览缩略图与实际封面采用相同裁切比例。波浪中的项目、选中档案和360°模型均显示这张封面，拆解时图片仍附着在盖板上。点击“保存信息”或“进入编辑”保存；切回预置后仍能重新选用最近上传的图片。旧自动保存不会覆盖更新的名称和封面。

从编辑器返回时会先提交待写入内容，再保留当前详情。再次进入同一项目复用已加载的编辑器；隐藏工作区会暂停播放与动画，已提交的导出任务可在后台继续。后端会话变化时缓存会重新准备。

首页 **任务** 打开任务中心，**恢复** 选择已有完整项目包。选中档案后，详情中的 **项目工具** 提供备份、该项目任务及适用工具；视频编辑器顶部也有 **工具** 入口。

## 任务中心

在首页点击 **任务**，或从顶部任务入口、项目工具中的 **查看项目任务** 打开。可切换当前项目与全部项目，按进行中、已完成或失败等状态筛选，查看阶段、进度、错误和结果链接，并返回所属项目。

任务中心汇总AI请求、素材分析、动画分镜预览与渲染、导出、项目备份和恢复等操作。只有支持取消或安全重试的任务显示相应按钮；关闭任务窗口不取消已提交的后台任务。应用重新启动后，原来未完成的任务会标为已中断，按需重新提交。

## 模型连接

在模型连接中填写服务商提供的API地址、模型名称和密钥。接口类型、超时和JSON模式位于“高级设置”；按服务商要求选择Chat Completions或Responses，JSON模式仅在支持时开启。列表不可读取时，可以手动填写模型名称。

支持本机安全存储时，首次默认勾选 **在本机加密保存密钥**。保存一次后，重新打开会自动读取；取消勾选并保存则只用于当前会话，**清除密钥** 会移除保存的密钥。换电脑或Windows账户时需要重新输入。

使用 Gx 快捷方式或程序启动入口打开即可自动恢复。普通浏览器直接输入本地网址时，只支持手动填写供当前会话使用。

保存后可测试连接，测试会发出真实短请求并可能使用服务额度。原生编辑器的其它可选服务单独配置。

不要把密钥放入项目正文、标题、截图或导出文件。应用不会自动把密钥重新发送到其它本地端口。

## 联网AI助手

复杂要求可先让助手列出计划，再连续处理。执行中可查看当前步骤；结束后查看 **本次结果**，区分已执行、已验证和未完成。源码改动可展开 **查看改动** 比较前后内容，并使用对应撤销入口。

发现可修复问题后，助手会接着修改和复查；缺少动作、停留、收尾或转场对照时，会补取对应画面。源码修改后，相关检查按当前版本重新确认，已有时间线结果也需同步更新。未检查的范围单列说明，**未完成**只列当前要求仍欠缺的部分；真实服务障碍或连续处理没有进展时，会说明具体原因并保留已有结果。

例如：“先检查当前工程，列出计划，只修改需要调整的动画源码，编译并看实际画面后再渲染加入。”助手可按行读取和搜索源码、精确修改指定位置；仍使用你配置的模型接口。

首页和各工作区都可以打开 **AI助手**。视频编辑器右侧的剪辑助手也使用同一套联网与工具流程，沿用已有的模型连接，不需另外配置搜索密钥。

1. 在 **本次项目** 中选择要处理的项目；只查公开资料时可用 **不选项目 · 联网问答**。
2. 选择 **自动处理** 或 **仅问答**。自动处理会按一句明确要求自行衔接所需工具，执行支持的项目修改；仅问答可以搜索和读取资料，不能改项目。
3. 直接输入问题或操作要求，例如“搜索这个主题的公开研究并列来源”“阅读这个论文网址解释主要结论”，或选中项目后要求“根据当前材料改写正文”。Enter发送，Shift+Enter换行。
4. 查看 **处理过程**。搜索、读取、生成和应用分别显示步骤与结果；有引用时点击 **来源** 打开原页。搜索片段不代表已阅读全文，访问受阻也不会显示成读取成功。
5. 已完成的修改会附带撤销入口。按结果中的 **撤销** 恢复对应文字或原生剪辑；同一项目后来又有改动时，会拒绝覆盖新内容。多步修改宜从最新一步开始核对和撤销。统一撤销记录在当前后台服务会话中有限保存，重启或过期后无法使用。

复杂任务会在同一任务中自动分批继续，不需要看见较多步骤后再反复发送“继续”。原来的固定步骤数和整项时间额度不再作为正常长任务的停止条件。每批沿用本次要求、项目、素材选择和时间轴范围，接着已有结果处理；切换批次不会重新建立请求，也不会从头重放已经完成的下载、导入或剪辑。较早过程可能滚动整理为摘要。

需要结束时点 **停止**。模型接口、下载、媒体处理和导出仍有各自的超时；若连续重复动作而没有进展，或反复失败，助手会停止并说明原因，保留已完成结果。暂时读不到进度时先点 **重新查看进度** 查询原任务。服务重启后未完成任务仍为已中断，先核对已完成修改再重新发起。

搜索默认使用Bing公开结果；网页读取支持公开HTML、文本及文字型PDF。读取或导入只使用你本轮提供的网址、真实搜索结果或已读网页中的链接；需要其它网址时先搜索，不会自行拼接带项目内容的查询参数。需要登录、访问验证或脚本运行的网页可能无法提取正文；扫描件不执行OCR。可以换用公开页面、导入本地资料或粘贴正文继续。来源和内容应自行核对，论文中的限定、研究对象和不确定性不应被讲解语气省略。

自动处理以当前对话为准，默认可以修改整个当前工程，不必先去界面选全片。需要局部修改时，可直接说“只改10–20秒”或“只改当前所选”；明确范围外的内容会保留。询问用法、只要建议及仅问答模式不执行工程修改。

处理时点 **停止** 可取消后续模型、联网和工具步骤；已经成功提交的修改保留，可检查后撤销。关闭助手窗口不会取消后台任务，再打开可接着查看；网络中断时点 **重新查看进度**，避免立即重复提交同一修改。服务重启后未完成任务标为已中断，需要重新发送要求，不会自动重新执行。

助手能调用的范围是Gx提供的文案、科普和剪辑工具；它没有任意终端、全盘文件、外站发消息或发布能力。模型会收到本次要求、相关对话和完成任务所需的所选项目资料；联网查询会将关键词发送给搜索服务，读取网址会访问对应网站。详见项目根目录的隐私说明。

## 文案写作

1. 填写 **想写什么**，按需粘贴或导入材料。支持 TXT、Markdown、Word、文字型 PDF，单文件最多 10 MiB，正文最多 60,000 字符。
2. 选择稿件形式，或保持自动适配。读者、场景和篇幅可在 **补充需求** 中设置。
3. 如需参考，展开 **参考（可选）**，开启 **使用参考**。可粘贴文字，或选择已有项目的材料、作品；选择 **参考内容** 或 **只学写法**，也可按当前要求自动决定。
4. 点击 **开始写作**。内容参考的引用会注明来源，写法参考不提供事实。参考设置随工程保存，后续精修也会使用。
5. 直接编辑初稿，或使用 **更自然、精简、更清楚、更正式**。也可输入修改要求；选中正文时只修改该段。需要时使用 **撤销上次替换**，或复制、导出当前稿。

**写作习惯** 可设置身份、语气、常用写法和用词。勾选 **在这台电脑上记住** 可跨项目沿用，**清除习惯** 可移除这些设置。

编辑会自动保存。生成期间修改了材料、参考或稿件时，新结果会保留为候选，供比较后选择；保存失败时可重试，本机输入会保留。

## 科普工作区

科普入口直接是“导入材料 → 从公用库选择人物和场景 → 调整互动密度并开始讲解”。每次固定一个人物、一个背景、一个章节；人物可有多种表情，问题和选项按材料自动安排。科普区沿用“模型连接”配置，完整操作见后文“从材料开始互动讲解”。

## 原生视频工作区

### 进入工程与手动编辑

在项目详情确认进入视频编辑后，打开对应的原生电影工程。使用原生素材区、预览、多轨时间线、属性面板和画布进行剪切、顺序调整、音量、字幕及其它编辑；保存和导出以该电影工程为准。

旧视频项目首次进入时，会将受控素材、片段出入点、字幕和配乐转成原生工程，同时保留旧JSON与来源快照。后续原生编辑不会反向覆盖旧时间线快照，因此不要用旧JSON判断最新剪辑状态。

新复制的素材保留安全化原名并加短ID，字幕页带序号；已有工程不批量重命名，重新打开不会改写原电影。

工作台辅助导入会将文件流式保存到本机再检查，单文件最多2GB；原生素材导入使用原生工作流。导入到本地并不等于上传中转站。存在外部链接的素材，备份或AI处理前应先收集到工程中。

### AI粗剪与版本保护

视频页右侧的 **AI剪辑助手** 可以随时使用；顶部 **AI助手** 控制收起与展开。窄窗口默认收起助手；展开后可点击外侧或按Esc收起。拖动侧栏分隔条可调节宽度，也可以聚焦分隔条后用方向键调整；输入框可以拖高。输入要求后按Enter发送，Shift+Enter换行。明确的剪辑要求直接执行并显示结果；普通问答只讨论方案。

展开 **素材与位置** 选择允许AI使用的素材；“全部素材”取消后逐项勾选。放置位置可选 **自由创作**、**追加到末尾**、**指定时间插入**、**替换当前主轨** 或 **仅修改所选区间**。自由创作无需填写时间，AI按本轮要求和允许素材安排位置；也可直接在对话中说明只修改哪一段。具体位置使用秒数或时间码，选择会随项目保存。

已有视频网址时，助手优先读取或导入该链接；未要求另找参考时，不因读取失败搜索其他网页。B站含 `/pt/` 语言前缀的单个BV/av链接也可使用，番剧、直播和合集仍需提供单视频链接。

要求逐镜重建时，助手可分批读取整段参考的实际画面，记录文字、布局与运动，再用于Remotion源码生成和原片对照。无需另提供截图或时间区间；局部查看只是补细节，不会把整片缩成短动画。仅做视觉制作时可沿用原音，不以音频转写成功为前提。采样与对照只确认已读取的画面，不声称恢复了原始隐藏图层。

“继续、重试、开始制作”会沿用同工程未完成的目标。已经读取和登记的画面会校验原件后复用，准备完成后进入制作；真实接口或原件失败仍会显示具体原因，不把仅阅读或计划当作已制作。只借鉴参考风格时按你的创作时长制作，完整逐镜重建才对照原片全长。可播放成片必须实际渲染完成；仅保存源码会保留为未完成。

AI助手默认可以读取、操作整个当前工程。界面勾选、选区、放置方式和参考时码只作建议，以本轮对话要求为准；明确“只修改某段、不要加入、保留其他”仍会遵守。全部素材与参考资料可按页读取，未放到时间线的素材也可发现；只有真正导入素材和完成修改才会显示相应结果。助手可在准备后继续读图、取 Shotcraft 动效源码和调整计划，自主精修或重新安排现有工程。参考片段时间不会被当成作品编辑范围。原生编辑取消固定一小时增长和一天坐标限制，仍保留有效数据、实际源时长、归属、锁定、版本冲突和撤销检查。

助手支持12,000字符要求。长剪辑任务可连续分批处理，单次模型输出被截断时会保留目标和已完成操作，尝试一次分批恢复。时间线、轨道和关键帧会注明分页或省略情况；关键帧可按单片段、属性分页读取，部分修改会合并到原曲线，整体替换需核对当前曲线版本。

助手会先读取真实多轨片段和clipId，再执行分割、修剪、移动、删除、复制、变速、音量静音、淡入淡出、位置/缩放/旋转/不透明度、调色、数值关键帧和Gx字幕文字样式。可在同一要求中连续完成多项操作，分割后使用真实新ID继续。暖色、冷色、电影感等调色属于有限预设；关键帧支持位移、缩放、旋转和不透明度。点击消息下的撤销按钮可恢复该次操作；随后已有其它手动修改时会拒绝覆盖。

每个项目单独保存对话和输入草稿，功能切换或收起面板不会清空它们。AI对话使用工作台已有的模型地址、模型名与密钥。

**AI粗剪** 仍提供先审查方案再应用的入口：

打开辅助面板，根据所选素材名称、类型、尺寸、时长、来源脚本与项目参考生成方案。使用下述“素材分析”后，还会带入当前所选工程素材的有效区间、成功转写和抽样视觉摘要。只有本地技术分析时，模型仍没有原片语义依据；有分析也只覆盖所列证据，不能据此声称逐帧看完全部素材或识别音乐节拍。

检查方案后再应用。方案绑定读取时的原生版本；如果生成期间继续改了电影，应用旧方案会被拒绝，应刷新上下文并重新检查，不会自动覆盖新编辑。

指定时间插入会切分跨插入点的片段并顺延后续内容，画面、HTML字幕和音频保持同步。锁定轨道、未知时长、WebVTT字幕轨或不能保真切分的自定义动画会阻止插入；可改用末尾放置或先在编辑器中调整。整体替换仍要求主轨可完整表示。应用失败不会以部分方案覆盖工程。

只有字幕而没有新片段的请求，字幕继续使用原时间线绝对时间，不产生空白插入。写作脚本可独立保存，不自动覆盖原生字幕。脚本估时需要播放复核；转写时间属于源素材，还要按实际裁剪、变速和片段位置映射到成片。

### 分析原素材

点击 **工具 → 素材分析**，选择当前工程中的素材，填写各自的分析起点和终点，再点 **开始分析**。每次最多8项，单段最多30分钟、合计60分钟。

默认执行本地画面变化检测和关键帧抽取，结果展示源时间码、实际抽样图像及检测/采样区间。“画面变化估计”不是确定的镜头切换，“间隔采样”也不等于识别了画面内容。普通本地分析不下载语音模型，不会在后台自动转写。

可按需启用以下模型功能：

- **语音转写**：把所选区间在本地切成最长10分钟、约20MB的音频块，发到当前服务的语音转写接口；可另填兼容的转写模型和语言。服务返回句段时显示句段范围，只返回文字时标为分块范围，均不宣称逐字对齐。
- **生成AI内容摘要**：把少量实际关键帧与成功转写文字交给当前模型，可另填摘要模型；视频摘要需要模型接受图片。只描述有抽样证据的画面，不把技术检测摘要当作视觉语义理解。

这两项取决于所配置服务实际支持的接口和模型。未配置、不支持或部分失败时，窗口会说明状态，已完成的本地结果仍可查看。分析依据供粗剪和助手使用时，会再次核对当前工程、所选素材和文件内容；改过或移除的素材不会继续使用旧分析。恢复包中的缓存也需内容核验，复用缓存会保留原分析时间。

可复制时间码摘要、保存完整结果或点击 **刷新所选分析** 重做。关闭窗口后已提交任务继续运行，可从任务中心或重新打开本窗口查看；需要结束时点 **取消分析**。

### 文案与视频版本联动

点击 **工具 → 关联文案**，选择来源文案或科普项目并建立版本关联。建立关联记录当前来源基线；以后来源发生变化时，视频工具入口显示待处理数量。

点 **重新比较**，查看旁白、拟定字幕、分镜画面、建议时长的前后差异，勾选本次需要采用的变化，再点 **同步所选与手动草稿**。来源正文可以单独记为已阅。旧关联尚无基线时，也可先比较当前来源再选择同步。

同步更新视频旁白、拟定字幕与分镜草稿，现有film时间线、实际字幕图层和手动剪辑保持原样。手动修改过的草稿字段会保留并提示冲突；旁白可展开 **视频旁白草稿 · 可手动合并** 整理后显式保存。后续通过AI或导入工作流采用更新后的草稿。

比较后来源或目标草稿又有改动时，会要求重新比较，避免旧请求覆盖新内容。可点 **查看来源** 返回原文，或 **解除关联** 停止版本跟踪。

### 添加与选择参考

点击剪辑页 **参考**，上传视频/图片、粘贴文字，或输入视频网址。每条参考可勾选 **整体风格、剪辑手法、色彩滤镜、镜头构图、字幕排版、文案结构**，并填写自己的参考重点。只选需要借鉴的部分；参考素材单独保存，不会自动加入时间线。

展开某条的 **参考哪段 → 作品哪段**：

1. 视频参考勾选 **限定参考视频片段**，填源视频的起点和终点。可用 **播放位置设为起点／设为终点**，再用 **播放本段** 核对。
2. 勾选 **限定作品中的应用区间**，填写当前作品最终时间线范围；已有标记区间时，可用 **使用时间线所选区间**。
3. 例如“参考12—18秒 → 作品40—46秒”，表示只借鉴该段参考并应用到作品所列区间。每条参考独立绑定；作品区间未限定时用于全片。图片和文字也可限定作品区间。

时间可以填秒数或 `00:12.500`。终点需晚于起点，参考源区间不能超过参考视频时长；不完整或无效区间会提示修正。参考抽帧限定在所选源区间内，源时间与作品时间分别计算。应用方案前仍应检查目标边界和区间外的内容；跨边界片段需要保留其它属性时，可先在编辑器拆分。

最多8条，参考图片20MB、视频或网址下载200MB。视频按画面预算抽取1—3帧，全部参考共最多12帧。要分析参考画面，所选模型需支持图片输入；不支持时关闭“使用参考画面”，继续使用文字和重点。参考语音和音乐节拍暂不分析。

网址支持公开视频直链、B站单视频/分P/短链及YouTube单视频。平台、地域或网络限制可能导致读取失败，可换用本地文件；本功能不读取浏览器登录信息，不处理直播、合集、DRM或分段清单。源网址会保留在参考条目中。

### Remotion动画

打开 **Remotion自由创作**，用自然语言描述所需画面、结构、时长和节奏。AI直接原创多文件React/TypeScript工程，可自由组合组件、SVG、Canvas、图形、GLSL和本机受控图片/视频/音频。没有固定场景模板、8场或90秒的创作限制；Composition自己的尺寸、fps和durationInFrames决定实际作品。

**生成后优化画面** 默认开启：编译后抽取实际画面，检查并按反馈改进一次；可关闭以只生成源码。检查结果会显示镜头覆盖范围，模型不支持图片时明确标记未完成。节奏和声音仍需播放小样确认。

生成会使用已启用的参考画面及当前素材已有的分析结果，保留参考区间和借鉴重点；不会自动再做素材识别或语音转写。

生成后先检查工程，应用通过真实Remotion编译读取Composition列表，显示尺寸、帧率和时长；多个Composition可分别选择。代码在专用渲染浏览器中运行，不在应用主进程执行，不提供任意终端或全盘访问。所需素材使用本工程已导入资源，外部素材先下载/导入；依赖后台Worker或外部网络的组件可能明确报错，错误信息会保留供修改。

可展开源文件修改组件、CSS、SVG、JSON或GLSL，保存会核对工程revision，未返回的文件不会被AI清空。源码不符合语法时保留输入并显示实际编译反馈；可以继续让AI修复。旧作品资料保留只读兼容，新创作不再走旧模板。

先生成真实PNG预览，必要时制作短小样检查运动，再渲染完整MP4。加入时间线前核对本次素材与位置；渲染期间若原生工程、源码版本或选区已经改变，应用会要求重新核对，避免把旧结果加入错误位置。加入后可撤销；生成的成片也可继续使用原生剪辑和精确助手调整。

预览和渲染均可取消；已保存的源码及已完成输出保留，服务重启不自动重放未完成任务。完整.gxproject项目包会带上当前有效源码、入口、Composition、props和所用public资源，恢复为新工程ID，不带后台任务或浏览器配置，也不会自动编译执行。

### 导出和完整备份

使用原生编辑器导出时，会先执行 **导出前体检**；也可从 **工具 → 导出前体检** 手动检查。手动检查只返回问题，不自动开始导出。

快速检查核对实际引用媒体、片段出入点、时间范围、画面覆盖、字幕时序和明确画框、音轨与导出运行时。缺失或损坏媒体、无效范围、运行时不可用或检查期间工程又变化等问题，需要先修复再检查。留白、疑似无声、音量或字幕安全框等警告可定位核对，符合创作意图时再继续导出；有时间码的问题可回到编辑器定位。

按需点 **深度抽检源片段**，用本地媒体工具检测有限片段的黑场和静音：最多6段、每段12秒、总共60秒。快速检查与深检均没有渲染最终合成全片；字幕安全检查只涉及已知时间和画框，不测最终字形像素，也不测最终混音。成片完成后仍应播放检查画面、音量、字幕和时长。

完整备份可按以下步骤操作：

1. 在项目详情点击 **项目工具**，或在视频编辑器打开 **工具**，选择 **备份项目**。应用先保存并检查所需文件。
2. 查看缺失文件或外链等检查结果；外部素材先收集到工程，修复后重试。准备完成后点 **保存完整包**，保存 `.gxproject`。
3. 在首页点 **恢复**，选择该文件，等待逐文件核验，确认恢复后的项目名称，再点 **确认恢复为新项目**。现有同名项目保留，可保存核验报告。

完整包包含项目资料、原生film、受控媒体、页面、可恢复的原生设置与历史、参考及绑定、封面、分析缓存，以及直接关联的文案/科普来源；模型连接设置和密钥不随包迁移。恢复会分配新项目/素材ID并更新直接来源关系。分析缓存经媒体内容核对后才复用，无法核对者提示重新分析；不会把恢复缓存说成新完成的转写。

原生工程目录或原生项目导出也可单独保存；单独JSON只包含其已有资料和旧剪辑快照。换电脑时用完整项目包，可同时带上工作台参考库和来源版本记录。

工作台中转密钥默认仅会话；原生服务配置按其设置保存在本应用原生状态目录。主动AI操作会发送相应资料或元数据到用户选择的服务；参考画面使用抽样图片，原素材转写使用所选区间的音频分块，摘要使用少量关键帧与成功转写文字。本地镜头分析、编辑和渲染在本机完成。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 详情仍无项目 | 新建或打开实际保存的项目；空档案不会显示虚构方块 |
| 计划版本已变化 | 刷新原生上下文，再重新检查或生成方案 |
| 主轨暂不可粗剪 | 检查HTML、禁用、外链或不可读片段，先整理或修复 |
| 401、403、404、429 | 分别检查密钥权限、接口和模型ID、额度或限流 |
| 本地工作服务失联 | 重新使用桌面入口打开健康服务，不把密钥改发其它端口 |
| 原生编辑器尚未构建 | 源码版需生成Studio UI dist；发行版请使用完整程序目录 |
| 缺少FFmpeg或浏览器 | 保留发行资源，确认本机Edge/Chrome；源码版配置FFmpeg路径 |
| 素材分析只有镜头信息 | 本地检测不含语义或语音识别；按需启用转写/摘要并检查模型接口是否支持 |
| 转写显示分块范围 | 当前服务未返回句段时间，需要播放复核；分块范围不能当作逐字字幕 |
| 文案同步出现冲突 | 重新比较并整理手动草稿；已有film和手动剪辑会保留 |
| 体检出现留白或静音提示 | 定位检查，符合创作意图时可继续；缺失/坏媒体等错误需先修复 |
| 完整包检查失败 | 按报告补齐缺失或外链素材后重新备份；损坏包需换用有效备份 |
| 助手无法读取网页或PDF | 检查是否公开、需登录或访问验证；扫描PDF需先获得可读文字，单页图片可走媒体识别，也可粘贴正文 |
| 媒体已下载但未导入 | 查看具体步骤与错误，检查目标项目、原生版本、视觉/语音接口或媒体格式；保留的原件不代表处理已完成 |
| 视频识别没有转写 | 当前ASR未成功时仅有实际抽样画面资料；配置兼容语音接口后重试，不把未转写段落当作已识别 |
| 助手进度暂时无法读取 | 点“重新查看进度”查询已有任务；服务重启中断的请求需重新发送，先核对已完成修改 |
| 长任务显示自动接续 | 仍是原任务在继续处理，无需反复发送“继续”；可查看最近过程或点停止 |
| 助手因无进展停止 | 查看重复操作或失败原因，核对已完成结果，修正缺失条件后再发起 |
| 字幕不准 | 对照实际播放调整，源转写时间还需映射到最终剪辑 |
| JSON恢复后找不到最新视频 | 使用.gxproject或完整原生工程与媒体，JSON仅保留其关联资料和旧剪辑 |

许可证、商标和素材说明随源代码与发行文件保留，见第三方许可文档，不作为创作界面的额外署名入口。

## 在时间轴框选后让 AI 修改

1. 在主时间轴选择片段，或用 I/O 标记一个连续区间。
2. 点击“AI修改所选区间”，或在助手的“素材与位置”中读取当前时间轴所选区间。
3. 核对起止秒数，输入修改要求。该模式固定区间时长，区间外主轨、配乐及其它轨道不顺延。
4. 只改字幕时AI不重建主轨；局部字幕从该区间0秒计时，由应用放到正确位置。替换字幕也限定在可安全修改的区间内。
5. 结果可撤销。工程已改变、片段引用过期、时长不匹配或无法安全拆分时会停止应用，按提示刷新或先拆分片段。

自由Remotion成片加入固定区间时必须与该区间实际长度匹配；没有旧模板的3至90秒限制。帧率、素材长度或区间精度不匹配时会提示调整，不会自动扩大到全片。

## 从材料开始互动讲解

进入科普项目后直接显示三步，无需切换旧的资料、讲解或分镜页面。

### 1. 导入材料

上传文本型PDF、DOCX、TXT、Markdown，或粘贴文字。预览原文，选择本次要讲解的页段。可以选择原资料的多页/多节，生成结果仍合并为一个讲解章节、一个固定场景。

PDF最大32MB/800页，DOCX最大10MB，文本最大8MB；单次选用上限60,000字符。扫描页需先OCR、密码PDF需先解密，复杂公式和双栏顺序建议对照原文件检查。未选页段不发送给模型。

### 2. 选择人物和场景

从公用素材库各选一个人物和一个场景。若库中没有素材，打开“公用素材库”添加。公用库在本机不同项目间通用，不是上传到互联网社区。

人物可设置姓名、人设、语气和性格；这些字段可自行填写。一个人物可批量导入不同表情的PNG/JPEG/WebP立绘，最多12种表情。背景可选铺满或完整显示。每张图片最大12MB/4000万像素；公用库最多64张、合计100MB。新库为空，不提供内置人物、图片或场景。

日常项目仅存所选人物和场景的ID，不复制图片或人物资料。再次打开作品会使用库中的当前名字与图片；修改人设、语气和性格用于下一次生成，不会在后台自动改写现有讲解文字。在用人物、场景和表情有引用保护，先更换作品的选择后再删除。

### 3. 调整密度并开始

选择“少量 / 适中 / 密集”互动密度，可补充创作要求，再开始讲解。场景、章节和人物数量固定为一个；没有“读者对象”、固定题数或选项数输入。

模型根据材料中的知识点和可核对依据决定哪里提问、问多少题，以及每题2至6个选项。密度只调节穿插提问的频率，不要求为了凑数量编题。人设和语气可有个性，但科学表述必须忠实于材料的限定与结论。

## 阅读、编辑与导出

同一人物在固定背景中逐句讲解，表情可随对话切换。读完带题的对白后，点“开始答题”单独显示题目；作答时收起对白，查看反馈与原文依据后再继续讲解。自动播放遇到题目会等待作答。支持逐字显示、补全当前句、历史、存档读档与讲解编辑。

新生成内容会加强概念之间的衔接、原因与证据、例子及适用边界。题目侧重理解和应用，干扰项对应具体误区，反馈解释原因；资料不足时不硬凑题目。已有讲解文字不会自动改写，需要重新生成才能采用这些要求。

原文摘录匹配便于回查，不等于自动事实审核。答题存档绑定脚本内容；修改题干、选项或正确答案后，旧答题状态会提示从头开始。存档位于当前浏览器。

新生成有效后直接替换当前作品，不再建立候选版本或人物场景快照。失败和取消会保留当前文字。旧版多人物/多场景作品请按新流程重新生成，旧磁盘文件不被批量删除。

离线HTML在明确导出时内嵌当前图片和文字，可离线阅读；所用原图合计上限30MB。完整.gxproject项目包同样在明确导出时打包当前选择的公用资源；恢复到另一台电脑时写入目标公用库，遇到ID冲突新建条目，不覆盖已有素材。普通制作和阅读不会给每个项目建立图片副本。
