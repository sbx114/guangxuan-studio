# 光宣工作台使用指南

## 打开工作空间

完整解压 **光宣工作台-Windows-x64**，双击 **启动光宣工作台.cmd**，在Edge独立应用窗口使用工作台。需要已安装Node.js 24和Edge，本机已有这两项。首页包含视频剪辑、文案写作和科普工作室；前两个为当前功能，科普工作室标记为后续版本。

本机组织DeviceGuard策略阻止新Electron程序启动，兼容入口使用标准Edge窗口与本地Node服务，不修改系统策略。**光宣工作台.exe** 仍供允许运行的设备使用。关闭窗口后如需结束后台服务，双击 **停止本地服务.cmd**。

首次使用可点击 **体验写作示例**，或在剪辑工作区体验预置动画。预置内容不是本次实时AI生成；动画渲染和后续剪辑仍由本机实际执行，不需要API密钥。

## 配置模型连接

点击右上角 **连接AI** 或设置图标，填写中转服务提供的API基础地址、模型ID和API Key。

| 设置 | 说明 |
| --- | --- |
| 接口地址 | 完整API基础地址，通常包含 `/v1`；不要填登录页面 |
| 模型名称 | 使用服务商实际ID；“获取列表”不可用时手动输入 |
| 接口类型 | 按服务商能力选择Chat Completions或Responses |
| 等待超时 | 按接口响应情况调整 |
| JSON模式 | 仅在接口和模型支持时开启 |

点击 **保存配置**，再 **测试连接**。测试发出真实的短请求，可能使用服务额度。通过后再用短素材验证一轮实际工作和结构化输出。

同一文本模型用于写作、粗剪与动画编排。动画由本机Remotion模板渲染，无需文生图接口。

密钥默认保留在当前会话。Electron版可勾选 **在本机加密保存密钥**，通过当前系统账户恢复；Edge兼容窗口不提供这一原生加密选项。不要把密钥放入素材、项目标题、截图或导出文件。

## 文案写作

### 1. 素材与需求

新建项目，粘贴正文或导入TXT、Markdown、DOCX文件。来源链接用于留档，不代表应用已经自动读取整篇网页。

明确受众、语气、场景和篇幅，例如：“面向低年级学生，客观易懂，整理已举办讲座的回顾，正文约400字。”保留原文中的“暂定”“计划”等限定。点击 **AI提炼素材**，当前素材会发送到配置的接口。

### 2. 事实确认

逐条核对事实值与原文引句。引句匹配表示文字能在素材中找到，不证明事实卡解释正确或来源已获外部核实。

确认人物、日期、地点、数字和限定词后勾选 **已确认**。可修改或补充事实；只有核对全部条目后，才使用 **我已核对，确认全部**。

原始素材变化后，旧事实和草稿可能过期，应重新提取和确认。存在冲突时间或地点时，先由人确认有效版本。

### 3. 内容创作

根据已确认事实生成公众号推文、宣传海报、视频分镜和社群文案。可手动编辑，或使用 **AI改写** 调整受众和表达。

| 内容 | 检查重点 |
| --- | --- |
| 推文 | 标题、导语、事实与段落表达 |
| 海报 | 主标题长度、日期、条件及版面可读性 |
| 分镜 | 画面、旁白、字幕与设计时长是否对应 |
| 社群文案 | 行动信息是否完整，有无无依据承诺 |

分镜中的画面描述是制作建议，不是已经生成的镜头；秒数属于脚本设计，需在剪辑时检查。点击 **文案转入剪辑**，将分镜与旁白送入视频工作区。

### 4. 核查与导出

在 **核查与记录** 运行 **AI核查**，阅读具体问题和依据，再决定如何修改。未发现问题不等于已完成正式发布审核。

**导出**支持Word文档、当前内容Markdown、海报PNG、项目JSON，以及来源、提示词和人工修改记录。**项目档案**可打开、备份和导入项目。

制作记录中的模型等待时间是实际接口调用用时，不是完整制作耗时，也不是节省工时。

## 视频剪辑

### 素材和时间线

点击导入，选择本地视频、音频或静态图片。素材显示名称、类型、时长等信息，可在预览区查看。视频和图片加入画面时间线，音频用于配乐。

Edge兼容窗口和浏览器模式会将选择的文件流式传给本机Node服务，保存到本地媒体目录后检测格式。每个文件最多2GB，上传期限180秒，超时可重试或选择较小文件。这个导入步骤不把媒体发送给中转站，也不将整个视频转换为Base64或一次性装入内存。

用入点、出点调整保留范围，在播放位置分割片段，并调整顺序。静态图片默认设计时长4秒，可按需要调整片段时长。

Electron原生导入保留原文件引用，原文件移动、删除或改写后应重新导入；兼容窗口导入保存一份本地副本。JSON项目备份不包含全部媒体文件，迁移时需要另外保留素材或本地媒体副本。

### AI粗剪

输入脚本或创作要求，让AI根据素材元数据提出剪辑顺序和出入点建议。检查后应用到时间线，再手动修剪、分割或重排。

当前依据是素材名称、类型、时长、尺寸和脚本文字，**不分析视频画面**。它不能据此确认画面中的人物、动作或精彩瞬间；可在素材名称或脚本中补充明确的镜头说明。

### Remotion动画

输入内容，让AI编排结构化动画方案。JSON可以编辑，允许五类模板：

| 模板 | 用途 |
| --- | --- |
| `title` | 片头和主题标题 |
| `steps` | 步骤或流程说明 |
| `bars` | 数据条；数值需有真实依据 |
| `quote` | 文字强调；人物引语须有原始出处 |
| `outro` | 结尾和行动说明 |

支持16:9、9:16、1:1画幅，paper和dark主题，30fps。每场3—12秒，最多8场，总长不超过90秒。应用校验方案后使用固定模板渲染，不执行AI生成的任意程序。

等待渲染任务完成，MP4会进入素材库，可继续裁剪、配字幕与音乐。动画资产保留方案及相关元数据。

不填密钥时可加载 **预置动画演示** 并真实渲染。展示时说明“方案为预置，视频由本机实际渲染”，不要说成实时AI生成。

### 字幕、配乐与MP4

字幕可手动填写时间和内容，也可使用脚本文案估时。**估时不是语音识别时间轴**，需对照实际播放调整。

选择配乐并调整配乐、原声音量。导出时实际拼接片段，按画幅缩放并补黑边，混合音轨并烧录字幕。

选择画幅和720/1080分辨率，提交MP4导出任务。完成后保存，并检查衔接、字幕位置、音量与总时长。本版单次导出支持最多200个画面片段、总长不超过60分钟。

## 本地数据与运行条件

项目、媒体索引、生成素材与导出文件保存在本机。兼容入口的数据目录为 `%LOCALAPPDATA%\GuangxuanStudio`；Electron版使用其应用用户数据目录。删除项目记录不会删除最初导入的媒体原文件。

主动使用AI时，任务需要的资料、事实、脚本或元数据会发送到中转接口；“本地保存”不等于AI全程离线。应用不自动发稿到外部平台。

发行目录提供FFmpeg与FFprobe。兼容启动需要Node.js 24和Edge；源码运行先安装项目依赖，也可用 `node server.mjs` 打开本地工作区。Electron版的Remotion可使用Edge或Chrome，更换系统账户后加密密钥可能需重新输入。

## 常见问题

| 现象 | 处理方法 |
| --- | --- |
| 401、403 | 检查密钥、模型权限与服务配置 |
| 404 | 核对API路径、接口类型和模型ID |
| 429 | 检查额度或限流情况，稍后重试 |
| 模型列表不可读 | 手动填写已知可用ID，再测试连接 |
| 模型JSON不完整 | 检查JSON模式兼容性，缩短要求或换模型 |
| 动画校验不通过 | 检查模板、主题、时长和必填文字，不要加入代码 |
| FFmpeg不可用 | 完整解压发行目录；源码模式配置两个可执行文件路径 |
| Electron被组织策略阻止 | 使用标准的启动光宣工作台.cmd兼容入口，保留系统策略 |
| 上传超时或过大 | 单文件不超过2GB，180秒内上传；缩小文件或重试 |
| 动画浏览器不可用 | 安装Edge或Chrome后重新打开应用 |
| 素材找不到或已变化 | 重新导入移动或修改后的文件 |
| 字幕时间不准 | 对照播放调整；脚本文案仅提供估时，不是ASR结果 |

报错排查通常只需接口类型、模型名、错误代码和脱敏操作说明，不要公开密钥。
