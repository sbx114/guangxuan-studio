# Pinned Shotcraft source references

This directory contains original upstream source files stored as plain `.source.txt` data, not installed or executable templates. `remotion-reference-library.mjs` accepts only reviewed index keys and verifies source bytes before returning text to the AI for independent adaptation.

Upstream: https://github.com/Vincentwei1021/video-shotcraft

Commit: `075b548c2405a07b77129eb448b0b504fc60dea3`

The full Apache-2.0 LICENSE and the upstream shot attribution document are retained here. The pinned tree has no separate NOTICE file. `origin-manifest.json` records every original path, Git blob SHA, SHA256, dependency and adaptation note. No upstream media or screenshots are included.

References cover composable motion math, camera coordinates and rasterization, real-video looping, typography anchoring, continuous braking, frame-rate/time semantics, and manifest-to-track mapping. They do not restrict the user's creative styles, scene count, duration or choice of React components.
